# 《妹妹、他人、妄想症》NVDA 无障碍辅助插件

本插件为视觉小说《妹妹、他人、妄想症》(Sister Other Paranoia) 提供 NVDA 屏幕阅读支持，让视障玩家也能完整游玩这款游戏。

## 功能

- 自动朗读游戏对话文本（含角色名），逐句播报
- 播报读心心声内容（主角读取他人内心时的浮动文字）
- 播报选项列表，并提示用方向键选择、回车确认；选择后播报结果
- 播报菜单、按钮等界面元素（标题画面、设置、存档读档、画廊等）
- 回显“读心输入”时键入的内容，输入完成后播报确认
- 播报快进/自动播放等模式切换
- 对话历史浏览：随时回听之前的所有对话与事件
- 完整的中文设置面板，可逐项开关播报内容

## 安装

1. 安装并运行 [NVDA](https://www.nvaccess.org/)（推荐 2026.1 或更新版本）
2. 双击 `sopAccess-1.0.0.nvda-addon` 安装本插件，按提示重启 NVDA
3. 将游戏插件 `SopAccess.dll` 复制到游戏目录 `BepInEx\plugins\` 下（若使用整合包则已包含）

> 游戏插件基于 BepInEx 5（x64），需要游戏目录中存在 `winhttp.dll`、`doorstop_config.ini` 与 `BepInEx` 文件夹，BepInEx 运行时会在首次启动游戏时自动生成。

## 使用

1. 先启动 NVDA，再启动游戏
2. 听到“《妹妹、他人、妄想症》辅助已连接”后即可正常游玩
3. 游戏中的操作方式与平常一致：
   - 点击 / 回车：推进对话
   - 方向键 + 回车：在选项间选择
   - 游戏界面中的按钮可用 Tab / 方向键 / 回车操作（与普通 Windows 程序不同，Unity 游戏内按钮主要靠方向键与回车）

## 快捷键（可在 NVDA 菜单 → 输入手势中自定义）

| 快捷键 | 功能 |
| --- | --- |
| NVDA+Alt+上箭头 | 朗读上一句对话/事件 |
| NVDA+Alt+下箭头 | 朗读下一句对话/事件 |
| NVDA+Alt+Home | 回到最新一句 |
| NVDA+Alt+H | 打开完整对话历史窗口 |
| NVDA+Alt+S | 复读当前最新一句对话 |
| NVDA+Alt+C | 复读当前选项 |
| NVDA+Alt+T | 静音/恢复播报 |
| NVDA+Alt+右箭头 | 切换到下一个可点击位置（场景热点） |
| NVDA+Alt+回车 | 点击当前可点击位置（自动移动光标并模拟点击） |
| NVDA+Alt+1 ~ NVDA+Alt+9 | 直接点击第 1~9 个可点击位置 |
| NVDA+Alt+G | 导出当前场景剧本原文到 %TEMP%（解谜/排查用） |
| NVDA+Alt+F | 导出当前场景可点击对象诊断（排查用） |

- **菜单与选项反馈**：菜单/选项出现后，用上下方向键移动高亮，插件会实时朗读当前焦点；回车确认。
- **需要鼠标点击的场景**：插件播报「可点击位置 N 个：1、名称（屏幕方位）…」，位置按左上→右下编号；
  用 NVDA+Alt+数字键 直接点击对应位置，或 NVDA+Alt+右箭头 切换后用 NVDA+Alt+回车 点击。

## 设置

NVDA 菜单 → 选项 → 设置 → “妹妹、他人、妄想症 辅助”，可配置：

- 监听端口（需与游戏插件一致，默认 42137）
- 各类播报内容的开关（对话、心声、选项、界面、输入、模式）
- 说话人格式、心声前缀
- 对话历史条数与输入回显间隔

## 常见问题

- **听不到任何播报**：确认 NVDA 已先于游戏启动；确认游戏目录 `BepInEx\LogOutput.log` 中有 `SopAccess: connected to NVDA addon listener`；确认端口一致。
- **中文朗读**：请确保 NVDA 语音合成器支持中文（如系统自带 Microsoft Huihui / Xiaoxiao）。
- **选项选择**：听到选项播报后，用上下方向键移动高亮（游戏会发出音效提示），按回车确认，随后插件会播报“已选择：……”。
